# Bot-Rescue - Robô de Resgate

Este repositório contém o código-fonte desenvolvido para o Trabalho de Conclusão de Curso (TCC). O projeto consiste em um robô de resgate autônomo projetado para localização de vítimas.

## Funcionalidades
* **Identificação Térmica:** Detecta a presença de pessoas através de sensores de temperatura.
* **Sinalização Visual:** Utiliza um LED RGB para indicar o status da busca e a detecção.
* **Sinalização Sonora:** Emite alertas por meio de um Buzzer ao localizar uma vítima.

## Componentes Utilizados
* Sensor de Temperatura MLX90614 
* LED RGB
* Buzzer
* Microcontrolador ESP32
